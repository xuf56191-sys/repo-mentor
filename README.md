# RepoMentor

RepoMentor 是一个面向开源初学者的代码仓库学习导航 Agent。

它将根据用户的技术基础、学习目标和可用时间，分析代码仓库的 README、目录结构和关键文件，并生成个性化的代码阅读路线。

## 项目背景

初学者第一次接触开源项目时，通常会遇到以下问题：

- 不知道应该从哪个文件开始阅读；
- 不理解项目目录中各个模块的作用；
- 无法判断哪些代码是当前阶段必须学习的；
- 学习过程缺少清晰的任务和反馈；
- 阅读一段时间后，无法判断自己是否真正掌握。

RepoMentor 希望帮助用户把复杂的开源仓库拆解成一个个可以完成的学习任务。

## 项目结构

```text
repo-mentor/
├── src/
│   └── repo_mentor/
│       ├── __init__.py
│       ├── config.py
│       └── main.py
│       └── llm_service.py
├── data/
│   └── demo_repo/
│       ├── user_profile.json
│       ├── README.md
│       └── tree.txt
├── docs/
│   └── learning-log.md
├── .env.example
├── .gitignore
├── requirements.txt
└── README.md
```

各个核心文件的作用：

- `main.py`：读取演示用户资料、README 和目录结构；
- `config.py`：读取并校验模型配置；
- `llm_service.py`：创建 DeepSeek 模型并完成模型调用；
- `user_profile.json`：保存演示用户的学习基础和目标；
- `tree.txt`：保存演示仓库目录结构；
- `.env.example`：提供环境变量配置模板；
- `learning-log.md`：记录项目开发过程和学习复盘。

## 环境配置

项目使用 `.env` 保存本地模型配置。

首先复制项目根目录中的：

```text
.env.example
```
并创建一个新的：
```text
.env
```
在`.env`文件中填写自己的大模型
```aiexclude
MODEL_PROVIDER：模型服务提供商；
MODEL_NAME：使用的模型名称；
MODEL_API_KEY：模型平台提供的 API Key；
MODEL_BASE_URL：自定义接口地址，没有时可以留空；
TEMPERATURE：模型生成随机性，当前建议设置为 0.2
```
## 运行方式

创建并激活 Python 虚拟环境后，安装依赖：

```bash
pip install -r requirements.txt
```

运行当前版本：

```bash
python -m src.repo_mentor.config
```
