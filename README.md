# RepoMentor

RepoMentor 是一个面向开源初学者的代码仓库学习导航 Agent。

它将根据用户的技术基础、学习目标和可用时间，分析代码仓库的 README、目录结构和关键文件，并生成个性化的代码阅读路线。

## 项目背景

初学者第一次接触开源项目时，通常会遇到以下问题：

- 不知道应该从哪个文件开始阅读；
- 不理解项目目录中各个模块的作用；
- 无法判断哪些代码是当前阶段必须学习的；
- 学习过程缺少清晰的任务和反馈；
- 阅读一段时间后，无法判断自己是否真正掌握。

RepoMentor 希望帮助用户把复杂的开源仓库拆解成一个个可以完成的学习任务。

## 当前版本

当前版本为 V0.1。

现阶段主要目标是读取以下输入：

1. 用户当前技术基础；
2. 用户学习目标；
3. 用户每天可投入的时间；
4. 仓库 README；
5. 仓库目录结构。

当前程序可以读取并展示这些测试数据。

## 后续计划

项目将按照以下顺序逐步开发：

1. 调用大模型生成学习路线；
2. 使用 Pydantic生成结构化结果；
3. 自动读取本地代码仓库；
4. 增加仓库读取工具；
5. 使用 LangGraph管理工作流；
6. 增加代码库问答；
7. 增加测验和学习反馈；
8. 保存用户学习进度。

## 当前暂不实现

为了控制项目难度，当前版本暂时不实现：

- 多 Agent；
- 自动运行仓库代码；
- 自动修改代码；
- 自动提交 Pull Request；
- 大型代码仓库分析；
- 向量数据库；
- 复杂网页前端。

## 运行方式

创建并激活 Python 虚拟环境后，安装依赖：

```bash
pip install -r requirements.txt
```

运行当前版本：

```bash
python -m src.repo_mentor.main
```
