# RepoMentor 产品定位

## 1. 项目要解决的问题

开源初学者第一次接触陌生仓库时，通常不仅是不理解代码，还会遇到以下问题：

- 不知道为了完成当前目标应该先学什么；
- 不知道目标任务与哪些文件、模块有关；
- 不知道应该按照什么顺序阅读代码；
- 不知道阅读完代码后应该做什么实践；
- 不知道自己是否真正掌握了相关内容；
- 不知道自己是否已经具备尝试目标 Issue 的能力。

RepoMentor 希望帮助用户从“面对陌生仓库无从下手”，逐步走到“具备尝试第一个真实贡献任务的能力”。

## 2. 一句话定位

RepoMentor 是一个面向开源贡献新人的自适应仓库学习与贡献准备 Agent。

它根据用户的技术基础、可用时间、目标任务或目标 Issue，以及仓库中的真实内容，生成有证据支持的个性化学习路线。

系统还会通过阅读任务、代码定位题、实践任务和测验评估用户的掌握情况，并根据薄弱点调整后续计划。

## 3. 核心用户

RepoMentor 主要面向：

- 第一次接触陌生开源仓库的学习者；
- 不知道应该从哪些文件开始阅读的新手；
- 希望完成第一个开源 Issue，但缺少前置知识的用户；
- 需要把仓库学习过程拆解为每日任务的用户。

RepoMentor 当前不面向：

- 已经熟悉目标仓库的核心维护者；
- 需要分析百万行大型仓库完整架构的专业团队；
- 希望 Agent 自动修改代码并提交 PR 的用户。

## 4. 核心输入

RepoMentor 的主要输入包括：

### 学习者画像

- 已掌握的技能；
- 不熟悉的技能；
- 项目经验；
- 每天可用学习时间；
- 可用学习天数。

### 目标任务

目标可以是：

- 理解一个模块；
- 学习某种技术在仓库中的实现；
- 新增一个简单功能；
- 补充一个测试；
- 修改一份文档；
- 尝试解决一个具体 Issue。

### 仓库信息

- README；
- CONTRIBUTING；
- 目录结构；
- 配置文件；
- 与目标任务相关的源码；
- 测试文件；
- 项目文档。

## 5. 核心输出

RepoMentor 不只输出一份普通的仓库分析报告。

它应该输出：

- 用户目前已有的能力；
- 完成目标仍然缺少的知识；
- 推荐阅读的真实文件；
- 推荐每个文件的原因；
- 建议的阅读顺序；
- 每日学习任务；
- 代码定位任务；
- 小型实践任务；
- 每个任务的完成标准；
- 基于仓库内容的测验；
- 用户薄弱知识点；
- 调整后的学习计划；
- 目标任务贡献准备度。

## 6. 核心工作流程

```text
学习者画像
→ 分析目标任务
→ 收集仓库证据
→ 识别能力差距
→ 生成个性化学习路线
→ 完成阅读和实践任务
→ 进行掌握度评估
→ 更新学习者画像
→ 调整后续学习路线
→ 评估贡献准备度
