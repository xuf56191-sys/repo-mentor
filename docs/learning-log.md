## 2026-07-30:：模型配置管理

### 今天的目标

为RepoMentor建立模型配置读取和校验功能。

### 今天完成

- 创建`.env`虚拟环境配置文件；
- 创建`.env.example`配置模板；
- 获取deep seek api并添加在配置文件中；
- 使用`python-dotenv`读取环境变量；
- 增加Temperature格式和范围检查；
- 验证真实API Key不会输出到终端；
- 编写并运行config.py文件获取配置文件内容。

### 今天理解的内容

- `.env`保存本地真实配置，不能上传GitHub；
- `.env.example`只保存字段模板，可以上传；
- API Key不能直接写在Python代码中；
- 配置读取和模型调用应该分开；
- 程序应该在启动阶段尽早发现配置错误。
